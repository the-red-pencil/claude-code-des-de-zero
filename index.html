Instal·la-la com una app

  • iPhone o iPad (Safari): botó Compartir → "Afegeix a la pantalla d'inici".
  • Android (Chrome): menú ⋮ → "Instal·la l'aplicació".
  • Mac o Windows (Chrome o Edge): icona d'instal·lar de la barra d'adreces, o menú → "Instal·la Claude Code AM".
